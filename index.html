Volunteer Tracker

Keep every hour you give.

Log shifts, track hours per organization, and print reports for school, work, or awards.

  • Your data is saved as a JSON file in your own Google Drive. Nothing is stored on a server.
  • Access to Drive is limited to the file this app creates.
  • Works on any device you sign in from.

Signing in opens a Google window asking permission to see your profile and to manage files this app creates in Drive.

Set up (site owner)
No Google client ID is configured yet, so sign-in is disabled. Follow the steps below once.
  1. In Google Cloud Console, create a project and enable the Google Drive API.
  2. Under OAuth consent screen, create an External app, add your Google account as a test user, and add the scope .../auth/drive.file.
  3. Under Credentials, create an OAuth client ID of type Web application and add this site as an authorized JavaScript origin:
  4. Paste the client ID into js/config.js (or below, for this browser only).

A client ID is set in js/config.js, so it can't be overridden here.
